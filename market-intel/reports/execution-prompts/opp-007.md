# Right-to-Work Automated Document Checker — Execution Brief

> The simplest way for UK SMEs to track right-to-work documents, prevent expiry, and pass a Home Office inspection.

## Product Vision

### What it does
A web application that stores employee right-to-work documents, recognises document types automatically using AI, tracks expiry dates, integrates with the UKVI share code system for real-time eVisa status checks, and sends alerts at 90/60/30 days before expiry. Produces an audit-ready evidence pack for Home Office inspections.

### Who it serves
UK SMEs with 10-200 employees in high-turnover sectors: hospitality, healthcare, construction, agriculture, food processing. HR managers and business owners who currently track right-to-work in spreadsheets or rely on memory.

### Why it matters
A Home Office survey in April 2025 found 80% of UK employers answer at least one RTW compliance question incorrectly. Civil penalties reach £60,000 per worker for illegal employment. Post-Brexit, the range of valid documents expanded (BRP, eVisa, UKVI share code system) while also becoming more complex. Employers must re-check time-limited permission holders before their permission expires — a requirement many miss. Most SMEs have no systematic process.

## User Personas

### Primary: HR Manager or Office Administrator (10-50 employee SME)
- **Context**: Responsible for onboarding new staff, maintaining employee files, handling all HR admin. Right-to-work is one of many compliance tasks competing for attention.
- **Pain points**:
  - Doesn't know which documents are valid for which nationalities
  - Passport expiry ≠ right-to-work expiry — easy to confuse
  - Time-limited workers (visa holders) need re-checking, but no system tracks when
  - A Home Office audit would expose gaps immediately
  - UKVI share code process is unfamiliar and changes periodically
- **Success looks like**: Every employee has a compliant RTW record. Expiry alerts arrive 90 days in advance. Could produce a complete audit pack in 10 minutes.

### Secondary: Business Owner (under 10 employees)
- **Context**: No dedicated HR. Personally handles all compliance alongside running the business. Relies on memory and a paper file. Has never been audited but knows it's a risk.
- **Pain points**:
  - No time to research the correct process
  - Doesn't know what a Home Office inspection looks like
  - Needs something fast, cheap, and reliable

## MVP Requirements (4-week scope)

### Core features
1. Employee register with profile (name, nationality, employment start date, job title)
2. Document upload per employee (passport photo page, BRP, visa vignette, share code proof)
3. AI document type recognition (what document is this? what is the expiry date?)
4. UKVI share code lookup integration (employer-side check)
5. Compliance status per employee: Compliant / Expiring Soon / Expired / Not Checked
6. Email alert system: 90 / 60 / 30 / 0 days before expiry
7. Audit trail: timestamped record of every check performed
8. Document checklist by nationality (UK/Irish — no check needed; EU settled status; BRP holders; visa holders)

### User flows

**Flow 1: New employee onboarding**
1. Add employee profile (name, start date, nationality)
2. System shows document checklist for that nationality
3. Upload document photos/scans
4. AI identifies document type and extracts expiry date
5. User confirms or corrects
6. Employee marked Compliant or flagged if wrong document type

**Flow 2: Share code check (EU/EEA employees)**
1. Employee provides their share code
2. Enter share code + employee date of birth
3. System calls UKVI API and displays: right to work status, restrictions, expiry
4. Result saved to audit trail with timestamp

**Flow 3: Expiry monitoring**
1. Dashboard shows all employees with expiring documents in next 90 days
2. Click employee → see document, expiry, and "Re-check" action
3. System sends automated email alerts to HR manager on schedule

**Flow 4: Home Office audit export**
1. Select date range or all employees
2. Export PDF audit pack: employee list, document types, check dates, share code results, expiry tracking history

### Required screens/pages
- Dashboard: compliance score, expiring soon count, recently added employees
- Employee list: sortable/filterable by status, nationality, department
- Employee profile: documents, check history, compliance status
- Add/onboard employee: guided flow with nationality-specific checklist
- Share code checker: standalone tool for quick UKVI checks
- Alerts settings: configure email recipients and alert schedule
- Audit export: generate inspection-ready report

### Admin functionality
- Multi-site support (companies with multiple locations)
- User roles: HR Admin (full access) vs. Manager (view-only for their team)
- Bulk CSV import of employee list

### Authentication
- Email + password with optional SSO (Google Workspace, Microsoft 365)
- Company accounts with up to 5 user seats in base plan

### Billing

## Technical Architecture

### Frontend
- Next.js 14 (App Router)
- Tailwind CSS + shadcn/ui
- React Dropzone for document upload
- Deployed on Vercel

### Backend
- Next.js API routes
- PostgreSQL (Railway or Supabase)
- S3-compatible storage (Cloudflare R2) for employee documents — encrypted at rest
- Background jobs via Inngest for daily expiry checks and alert sending

### Database
- `companies`: id, name, billing_plan, seats_limit
- `employees`: id, company_id, name, nationality, start_date, status (compliant/expiring/expired)
- `documents`: id, employee_id, doc_type, expiry_date, s3_key, uploaded_at, verified_at
- `share_code_checks`: id, employee_id, share_code, check_date, result_json, performed_by
- `audit_events`: id, company_id, employee_id, event_type, performed_by, timestamp

### API requirements
- **UKVI Employer Checking Service API**: Official UKVI API for share code checks. Register at gov.uk. Free. Response confirms right to work and any conditions.
- **Claude API**: Document type recognition and expiry date extraction. Volume: 10-50 calls/day at launch. Cost: ~£5-15/month.
- **SendGrid or Resend**: Email alerts. Cost: free tier covers initial volume.

### AI model usage
- **Document recognition prompt**: "Identify the type of this document (UK passport, BRP card, visa vignette, EU settlement scheme letter, or other) and extract the expiry date if present. Return JSON: {doc_type: string, expiry_date: string|null, confidence: high|medium|low, notes: string}"
- Use `claude-haiku-4-5` for speed and cost at this simple classification task. Cost ~£0.002 per document.
- Do NOT use AI for RTW eligibility determination — use a rules-based lookup table keyed by nationality and document type.

### Hosting
- Vercel: ~£20/month
- Railway (DB): ~£15-25/month
- Cloudflare R2: ~£3/month (documents are small)
- Total infra: ~£40-50/month at launch

### Scalability
- MVP holds to 500 companies with 200 employees each. Beyond that, move to dedicated worker for expiry checks.
- Document encryption keys must be per-company (not shared) for GDPR compliance.

## Data Model

### Core entities
- **Company**: Organisation account. Has billing plan and seat limits.
- **Employee**: Individual worker. Has nationality, start date, compliance status.
- **Document**: Uploaded file. Has doc_type, expiry_date, and S3 key.
- **ShareCodeCheck**: UKVI API result. Immutable audit record.
- **AuditEvent**: Every compliance action. Immutable. Used for Home Office inspection exports.

### Important metadata
- Documents stored encrypted at rest — GDPR requirement (passport copies are sensitive personal data)
- AuditEvents are immutable and append-only — never allow deletion
- Employees soft-deleted (mark inactive, don't delete) to preserve audit history
- `verified_at` timestamp on documents: when the employer confirmed they physically checked the original

## AI Usage Details

### Where AI adds value
1. **Document type recognition**: Automatically identifies passport, BRP, visa from a photo upload — removes manual selection step
2. **Expiry date extraction**: Pulls the expiry date from document image — saves manual entry

### Where deterministic systems are better
- **RTW eligibility logic**: Which documents are valid for which nationalities is a rules table, not AI. Must be 100% accurate and auditable.
- **Share code verification**: Always use the official UKVI API. Never AI.
- **Alert scheduling**: Rules-based calendar logic.
- **Audit trail**: Deterministic append-only logging.

### Prompting suggestions
Keep the document recognition prompt tight and specific. Test against the full list of valid UK RTW documents from the Home Office employer guide. Build a test suite of 50+ document images (use synthetic/test data) to validate extraction accuracy before launch.
