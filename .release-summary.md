Gravix is now an open-core project. The core is Apache-2.0 and free forever, a paid tier lives under
`ee/` as source-available BUSL-1.1, and CI proves the split is real on every pull request: the core
builds and its tests pass with `ee/` physically deleted.

Feature parity with Datadog is still a non-goal and always will be. What changed is that Gravix now
claims to be better on four specific axes — correctness, recomputability, data ownership, and
billing predictability — and every one of those claims has to be provable before it ships. So this
release is mostly proof: a correctness suite that shows a recompute is byte-identical under
adversarial conditions, a benchmark harness a stranger can re-run, `gravix explain` to show where
any number came from, and an exit path that CI exercises by exporting everything and reading it back
with every Gravix service stopped.

The second half is about making the project contributable. One command sets up a checkout, the
suite you run before pushing finishes in under five minutes, plugins have an ABI that survives the
next release, governance is written down with no discretionary rung, and the RFC process turns the
charter's amendment procedure from a paragraph into something CI enforces.

If you are upgrading: nothing here changes the fact schema or the wire format, and there is no
migration.
