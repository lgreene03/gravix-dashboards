# CIS Subcontractor Risk Monitoring — Execution Brief

> Automated CIS compliance monitoring for UK construction contractors: continuous subcontractor verification, risk alerts, and MTD-ready monthly returns.

## Product Vision

### What it does
Maintains a live register of a contractor's subcontractors, performs automated monthly re-verification via HMRC's CIS API, flags changes in gross payment status, calculates CIS deductions on each payment, generates CIS300 monthly returns, and produces MTD ITSA-compatible digital records for subcontractors earning over £50k.

### Who it serves
UK construction contractors with 5-50 employees who engage 5-30 subcontractors. Owner-managers and finance/admin staff who currently track CIS obligations via spreadsheet or rely entirely on their accountant.

### Why it matters
April 2026 CIS reforms imposed a "knew or should have known" liability clause: if a contractor is party to a transaction connected with fraudulent tax evasion by a subcontractor, HMRC can immediately revoke their gross payment status — with the reapplication period extended from 1 to 5 years. Nil CIS returns are now mandatory even if no subcontractors were paid. Continuous subcontractor risk monitoring is now legally required behaviour, not optional best practice. Most small contractors have no system for this.

## User Personas

### Primary: Construction Firm Owner-Manager
- **Context**: Runs a building firm with 8-20 employees, regularly engages 5-15 subbies. Does the admin himself or has one office admin. Uses Xero for invoicing but CIS is tracked in a spreadsheet or handed to the accountant.
- **Pain points**:
  - Has to manually log into HMRC portal to verify each subcontractor
  - Doesn't know when a subcontractor's gross payment status changes
  - Unsure if their CIS deduction rates are always correct
  - Nil return requirement catches them out — forgot to submit last month
  - April 2026 changes feel threatening but unclear on what to do
- **Success looks like**: System automatically checks all subs monthly, alerts if anything changes, calculates deductions, and produces the monthly return ready to file.

### Secondary: Construction Firm Office Admin
- **Context**: Does payroll, invoicing, and CIS admin for a 15-30 person firm. Currently spends 4-6 hours/month on CIS reconciliation. Accountant reviews quarterly.
- **Pain points**:
  - Manual HMRC portal is slow and clunky
  - Mistakes in CIS deductions create end-of-year accountant rework
  - New liability rules make her anxious about getting it wrong

## MVP Requirements (4-week scope)

### Core features
1. Subcontractor register (name, UTR/company number, trading status, payment status)
2. HMRC CIS verification API integration (verify status: gross / net / unmatched)
3. Automated monthly re-verification job with change detection and email alerts
4. Payment logging (date, gross amount, materials amount, CIS deduction calculated)
5. CIS300 monthly return generation (PDF summary matching HMRC format)
6. Nil return reminders (alert when no payments logged for the month)
7. Audit trail: every verification result stored with timestamp

### User flows

**Flow 1: Add a subcontractor**
1. Enter subcontractor name + UTR (or company registration number for Ltd companies)
2. System calls HMRC CIS API: returns gross / standard / unmatched
3. If unmatched: alert user — do not pay this subcontractor until verified
4. If gross: deduct 0%; if standard: deduct 20%; if unmatched: deduct 30%
5. Subcontractor added to register with current status and next re-check date

**Flow 2: Log a payment**
1. Select subcontractor from register
2. Enter gross payment amount and materials amount (if any)
3. System calculates CIS deduction: (gross - materials) × rate
4. Generates payment certificate (accessible to subcontractor)
5. Payment added to monthly return

**Flow 3: Monthly return**
1. End of month: dashboard shows month's payments and calculated deductions
2. System flags if nil return needed (no payments logged)
3. User reviews and approves
4. CIS300-format PDF generated for accountant or direct HMRC submission
5. Submission recorded in audit trail

**Flow 4: Status change alert**
1. Monthly re-verification job runs on 1st of each month
2. If any subcontractor's status has changed: email alert to account admin
3. Alert includes: old status, new status, affected payments, recommended action

### Required screens/pages
- Dashboard: total subs, status breakdown (gross/standard/unmatched), upcoming return due date, alerts
- Subcontractor register: list with status, last verified date, total paid this year
- Add/edit subcontractor: UTR entry, verification result, contact details
- Payment log: list of payments this month with deduction calculations
- Monthly return: review and export CIS300-format PDF
- Audit trail: full history of verifications and changes

### Admin functionality
- Multi-company support (accountants managing multiple firms)
- Export to CSV for Xero/QuickBooks accountant handoff
- HMRC submission confirmation logging (user marks as submitted)

### Authentication
- Email + password with MFA
- Company accounts with up to 3 user seats

### Billing

## Technical Architecture

### Frontend
- Next.js 14, Tailwind CSS + shadcn/ui
- Vercel deployment

### Backend
- Next.js API routes + separate worker service
- PostgreSQL (Railway) for all data
- Inngest for scheduled jobs (monthly re-verification, nil return reminders)
- Resend for transactional email alerts

### Database
- `companies`: id, name, billing_plan
- `subcontractors`: id, company_id, name, utr, company_number, current_status, last_verified_at, deduction_rate
- `verifications`: id, subcontractor_id, verified_at, result (gross/standard/unmatched), hmrc_response_json
- `payments`: id, subcontractor_id, payment_date, gross_amount, materials_amount, deduction_amount, month_year
- `monthly_returns`: id, company_id, month_year, total_paid, total_deducted, nil_return, submitted_at
- `audit_log`: id, company_id, action_type, actor_id, details_json, created_at

### API requirements
- **HMRC CIS Verification API**: Requires HMRC developer registration. Free. Returns gross/net/unmatched status per UTR lookup. Approval process takes 2-4 weeks — apply on day 1.
- **Companies House API**: Free. Use to look up Ltd company registration numbers for subcontractors registered as companies. Helps identify shell companies.
- **HMRC MTD ITSA API**: For generating MTD-compatible records (week 6+ feature). Requires separate developer registration.

### AI model usage
- AI is secondary in this product. Rules-based CIS deduction calculation must be exact.
- Optional: AI risk scoring from Companies House data patterns (age of company, SIC code, director history) to flag high-risk subcontractors.
- If AI risk scoring added, use `claude-haiku-4-5` for cost. Volume: ~200 company lookups/month. Cost: ~£2/month.

### Hosting
- Vercel: £20/month
- Railway (DB + jobs): £30-50/month
- Total: ~£50-70/month

## Data Model

### Core entities
- **Company**: Construction firm account.
- **Subcontractor**: Individual or Ltd company engaged for work. Has UTR/company number, current CIS status, deduction rate.
- **Verification**: HMRC API response. Immutable audit record. Append-only.
- **Payment**: Single payment to a subcontractor with calculated deduction. Links to monthly return.
- **MonthlyReturn**: Aggregated CIS300 data for a calendar month.

### Important metadata
- `verifications` table is append-only — never update or delete. Audit requirement.
- `deduction_rate` on subcontractor must always reflect the MOST RECENT verification result
- Payments reference the verification that was current at payment time (audit trail for "I used the correct rate at the time")

## AI Usage Details

### Where AI adds value
- **Subcontractor risk scoring**: Given Companies House data (company age, SIC code, director history, prior names), flag subcontractors that exhibit patterns associated with CIS fraud schemes.
- **HMRC correspondence parsing**: If user uploads HMRC letters, AI extracts key information (penalty amount, affected period, required action).

### Where deterministic systems are better
- **CIS deduction rate calculation**: Strictly rules-based. Never AI.
- **HMRC API verification**: Always live API call. Never cached beyond 24 hours.
- **Monthly return figures**: Must be exact arithmetic, not approximated.
- **Nil return detection**: Rules-based calendar logic.
